**Developer Note**

🧙 Originally written in **Unity (C#)**, this project is now being rebuilt in **Godot** with **Python** support.

* **Godot** allows the project to run on almost any "potato" device while keeping the entire codebase open source.
* **Python** makes it easier for you to inspect, understand, and customize the code that interacts with your hardware.
The Godot version is called **[GOMI](https://github.com/EloiStree/GOMI)**.

Godot also offers several advantages:
* Runtime code loading / modding
* A built-in visual scripting editor (similar to Scratch).
* A graph editor for visual programming.

Expect powerful tools for hardware remapping, automation, and QA testing.
